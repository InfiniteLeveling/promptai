--------------------------------------------------------------------------------
ARCHITECTURAL INVARIANTS & SECURITY PROTOCOLS (MUST MAINTAIN AT ALL TIMES)
--------------------------------------------------------------------------------
1. The Non-Executable Principle: The backend NEVER executes arbitrary untrusted shell commands, eval(), or user scripts. It synthesizes static specifications, JSON, and markdown prompts.
2. Zero Key Leakage: API keys (Gemini, GitHub, Auth0) are strictly encapsulated in server-side .env files. The client bundle must never receive or expose secret credentials.
3. Strict XML Boundary Encapsulation: All user inputs must be sanitized and encapsulated inside <raw_input>...</raw_input> XML boundary containers before passing to AI models to defend against prompt injection attacks.
4. Schema-First AST: All raw inputs compile into the standardized CanonicalRequirementSpec draft-07 JSON Schema before any target prompt is generated.
5. Graceful Fallback: If external AI services take > 8,000ms or fail with 5xx, the system must degrade gracefully and return actionable error payloads adhering to the standardized error schema.

POST /api/prompts/analyze

Passes raw user input to Stages 1-3. Returns domain classification, extracted constraints, heuristic score, and recommended clarification chips.

| | 
curl -X POST https://api.promptarchitect.ai/v1/analyze \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "raw_prompt": "Build a multi-tenant webhook dispatcher in TypeScript with PostgreSQL",
    "target_model": "google-antigravity",
    "strict_mode": true
  }'
const res = await fetch("https://api.promptarchitect.ai/v1/analyze", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    raw_prompt: "Build a multi-tenant webhook dispatcher in TypeScript with PostgreSQL",
    target_model: "google-antigravity",
    strict_mode: true
  })
});
const data = await res.json();
console.log("Quality Score:", data.heuristic_score);
import requests

response = requests.post(

Vibe Protocol

The Two-Prompt Execution Protocol

When executing autonomous workflows, always decouple the Architectural Contract from the Execution Blueprint:

Step 1: Ingest Prompt A

Directs the agent to author only documentation (`docs/SPEC.md`, `PRD.md`, schema diagrams). Zero codebase modifications permitted.

Step 2: User / Gate Review

Review the produced specifications to confirm DB relationships, error codes, and SLAs before any code is generated.

Step 3: Feed Prompt B

The agent executes atomic phases one-by-one against the locked specification, bookended by terminal test checkpoint commands.
